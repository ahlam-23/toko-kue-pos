# Toko Kue POS
1. Install XAMPP/Laragon, aktifkan Apache + MySQL.
2. Salin folder `toko-kue-pos` ke `htdocs` (XAMPP) atau `www` (Laragon).
3. Database: buka `install.php` di browser (otomatis), ATAU import `database.sql` lewat phpMyAdmin.
3b. (Opsional) edit `config/config.php` untuk kredensial DB dan nomor WhatsApp.
4. Buka `http://localhost/toko-kue-pos/install.php` sekali, lalu HAPUS file install.php.
5. Katalog: `http://localhost/toko-kue-pos/` | Login: `/login.php`
   Admin: admin / admin123 | Kasir: kasir / kasir123 (segera ganti di menu User)
